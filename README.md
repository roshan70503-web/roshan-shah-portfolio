# Roshan Shah — Portfolio

A responsive personal portfolio for Roshan Shah, aspiring Python Developer.

## Files
- `index.html` — portfolio homepage
- `resume.pdf` — downloadable 2027 resume

## Deploy with GitHub Pages
1. Create a new **public** GitHub repository, for example `roshan-shah-portfolio`.
2. Upload these three files directly into the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site.

Keep `index.html` and `resume.pdf` together in the repository root. The Download buttons use a same-site HTML `download` attribute and save the PDF as `Roshan_Shah_Resume_2027.pdf`. The Open resume button and embedded preview remain available as alternatives.
